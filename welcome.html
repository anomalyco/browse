OpenCode Browser

Lets your AI agents use this browser through the browse MCP tools: open and drive tabs, run Playwright, take screenshots, record, and hand off to you for logins.

Set up

Run this once in a terminal. It adds the browse tools to opencode.

npx opencode-browser-cli install

Status

Checking…

Pair with the relay

The extension only works for the relay on this computer once both know the same pairing code. Run npx opencode-browser-cli pair in a terminal and paste the code it prints.

Using it

  • Agents open their own tabs in a window of their own, which never comes to the front. Tabs nobody uses for 10 minutes close.
  • To let agents use a tab you have open, click the OpenCode Browser toolbar button on it. Click again to take it back, even while an agent is running.
  • When an agent needs you (a login, 2FA, a payment), the badge shows WAIT. Finish, then click the toolbar button (or Continue on the page).
