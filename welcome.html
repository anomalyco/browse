Browse

Lets your AI agents use this browser through the browse MCP tools: open and drive tabs, run Playwright, take screenshots, record, and hand off to you for logins.

Set up

Run this once in a terminal (it needs Node.js 22.19+). It installs the relay, adds the browse tools to opencode and pairs it with this extension.

npx @opencode/browse install

Connection

Checking…

The relay is on this computer (localhost) unless opencode runs on another one: then run npx @opencode/browse set hostname 0.0.0.0 there and enter that computer's Tailscale IP or name. A pairing code is only needed for a new relay, or after this browser was unpaired: run npx @opencode/browse pair on the relay's computer (from a checkout: node cli/dist/cli.mjs pair) and enter the code it prints. It works once, within 10 minutes.

This browser

Using it

  • Agents open their own tabs in the background of your window, grouped at the start of your tab strip and collapsed unless you're looking at one. Tabs nobody uses for a while close (after 10 minutes unless set otherwise above).
  • To let agents use a tab you have open, click the Browse toolbar button on it. Click again to take it back, even while an agent is running.
  • When an agent needs you (a login, 2FA, a payment), the badge shows WAIT and the page shows a card. Finish, then click Continue or the toolbar button.
  • Recordings show only the page. If an agent needs you while it records a tab, you get a notification instead of the card; click it to go to the tab.
