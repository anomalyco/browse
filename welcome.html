OpenCode Browser

Lets your AI agents use this browser through the browse MCP tools: open and drive tabs, run Playwright, take screenshots, record, and hand off to you for logins.

Set up

Run this once in a terminal (it needs Bun and Node.js 22+). It builds the relay, adds the browse tools to opencode and pairs an unpacked copy of this extension with it.

git clone https://github.com/anomalyco/browse.git && cd browse && bun run setup

Pair with the relay

The extension only obeys the relay on this computer once both know the same pairing code. Run node cli/dist/cli.mjs pair in your browse folder (or opencode-browser pair) and paste the code it prints.

Using it

  • Agents open their own tabs in the background of your window, grouped at the start of your tab strip and collapsed unless you're looking at one. Tabs nobody uses for a while close (after 10 minutes unless set otherwise above).
  • To let agents use a tab you have open, click the OpenCode Browser toolbar button on it. Click again to take it back, even while an agent is running.
  • When an agent needs you (a login, 2FA, a payment), the badge shows WAIT and the page shows a card. Finish, then click Continue or the toolbar button.
  • Recordings show only the page. If an agent needs you while it records a tab, you get a notification instead of the card; click it to go to the tab.
