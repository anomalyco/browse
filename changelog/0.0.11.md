summary: browse moves to standard XDG folders, updates through whatever installed it, and gives agents a smaller, cheaper set of tools. Most of this came from Aiden's review.
---
## Major
- browse no longer uses ~/.browse. Settings go in ~/.config/browse, data in ~/.local/share/browse, logs and state in ~/.local/state/browse, and the binary in ~/.local/bin/browse. Existing installs move over by themselves.
- Updating reruns whatever installed browse: the install script or npm. `browse rollback` is gone.

## Improvements
- Agents get short instructions when they connect instead of a separate skill tool.
- 18 tools instead of 29, each result is sent once, and execute returns its value once, so calls use far fewer tokens.
- Tool descriptions no longer change when browsers connect, so agents' prompt caches stay warm.
- Agents can't change auto-update anymore; you still can with `browse settings`.
- Read-only tabs are really read-only, and agents can't grant sites browser permissions.
- `browse install` without a terminal sets nothing up when it can't tell which agent ran it, and says how to pick one.

## Fixes
- Updates no longer get stuck after a cancelled request.
- The extension can't close your own tabs after a browser restart.
- A corrupt sessions.json no longer stops browse from starting.
- Shutdown and slow page scripts can't hang forever.
- The idle cleanup leaves named sessions alone.
- Agent configs are written in one step and no longer break when your node version changes.
- Connections that never pair are closed, with a small size limit before pairing.
