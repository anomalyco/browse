## Major
- Removed the secrets feature (stored site secrets, `secrets.type()` and the `secrets_*` tools). Leftover secret files are deleted on update.
- Removed the flight recorder, the ghost cursor and its setting, `browse doctor` (its checks are in `status` now), and `browse skill` (`browse --help` has a short agent guide instead).
- `browse mcp` is one process now, and `browse install` sets OpenCode up to share a single browse server across every project instead of one per directory.
- Recording uses the browser's debugger only. The extension no longer asks for the tab capture and offscreen permissions.

## Improvements
- The extension's settings and setup pages say when your browse CLI is out of date and which command updates it.
- Network capture returns redacted traffic directly; HAR export and its extra options are gone.
- Snapshots include iframe content and readonly field values, and fail fast on stale refs instead of waiting 30 seconds.
- Agent tabs open in the window you actually use, your viewport is restored after a script ends, and a session's tabs can stay visible between calls.
- `session new --browser` picks which browser a session uses, and pending handoffs show in session summaries.

## Fixes
- browse moves off port 19988 when another program holds it, waits longer for a busy browser, and shuts down cleanly.
- A stopped script no longer leaves a navigation hanging that blocks later ones.
- `browse mcp` exits when the agent goes away instead of lingering.
- Toolbar clicks made while browse is starting are no longer lost.
- Updates: no restarts on the same build, notify mode no longer says it will install, and old pre-0.0.11 installs move over instead of failing every update.
- Windows: no console flash when the relay starts, and install.ps1 works without Get-FileHash.
