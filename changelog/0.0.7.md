## Major
### Install without Node
`curl -fsSL https://opencode.ai/browse/install | sh` (or the PowerShell line on Windows) installs browse as a single binary, adds it to your PATH and sets up your agents. It keeps itself up to date. `npx @opencode/browse install` still works.
### A new setup page
The extension opens a short setup page: ask your agent to install browse, or run one line yourself. It ticks itself off as browse connects and your agent opens its first tab. Settings have their own page now.
## Improvements
- One install screen: the MCP entry for any agent, then the agents found on your computer, with search across 30 agents.
- `browse install --remote` connects the extension to an agent on another computer.
- Snapshots of large pages are much faster.
- The deadbolt sign-in integration is gone; site secrets you store yourself work as before.
## Fixes
- `npx @opencode/browse` 0.0.6 crashed on startup; it starts again.
- Error text from your code shows only its own stack frames.
- No JSON-value warning when your code returns nothing.
