## Major
### browse is one Rust binary
The CLI, relay and MCP server are a single native `browse` executable of a few MB, with no Node.js or Playwright underneath. The install script, `npx @opencode/browse install` and global npm, bun, pnpm, yarn and volta installs all run the same binary, and the extension from the Chrome Web Store works with it unchanged.
### Tools for every agent
OpenCode gets plain browser tools (`navigate`, `snapshot`, `click`, `fill`, `screenshot`, `network`, `recording` and more) to compose in code mode. Claude Code, Codex, Cursor and other MCP clients get `execute`, which runs JavaScript with a Playwright-style `page`, `snapshot()` and `handoff()`, plus `status` and `tabs`.
### Tabs are the handle
`navigate` opens a background tab and returns its id; every other call names that tab. Sessions and their tools are gone. Agent tabs keep their options (group, allowed sites, read-only, visible) and come back after a relay restart.

## Improvements
- `browse install` sets up OpenCode, Claude Code, Codex, Cursor, VS Code, Gemini CLI and 25 more agents again, with a searchable picker that remembers your last choice, `--agent <name>` and `-y` without asking, and edits that keep the comments and formatting of each agent's JSON, TOML or YAML config.
- `browse install` keeps exactly one browse: a global npm, bun, pnpm, yarn or volta install is left to its package manager (agents run its `browse`), npx and bunx runs are copied to `~/.local/bin` once and update themselves from then on, and a leftover second copy is removed or pointed out.
- Every install method updates itself: the binary from the release service, global installs with the package manager that installed them.
- `browse install --remote` and `browse set hostname 0.0.0.0` connect a browser on another computer again.
- `browse uninstall` removes browse from every agent it was added to, stops the relay and deletes its files.
- `browse status` lists the agents browse is set up in and says in plain words what the extension needs.
- The extension's settings page offers the update mode for install script installs too.

## Fixes
- The relay starts on a fallback port when another program holds 19988 on first use, instead of failing.
- `browse install` no longer opens a pairing link that can't work when the relay is pinned to another port with `OPENCODE_BROWSER_PORT`; it prints the address and code to enter instead.
- Unknown `browse install` options are refused instead of ignored.
