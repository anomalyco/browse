## Fixes
- The installed browse binary kept crashing its relay, dropping every agent's session, when the extension reconnected or a tab closed while a page was opening. It now shrugs it off and keeps going.
## Improvements
- Commands and messages say `browse <command>`, or `npx @opencode/browse <command>` if you installed with npx, instead of `opencode-browser`.
- The README leads with the one-line installer; Node.js is only needed for npx.
