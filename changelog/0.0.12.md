summary: Re-running `browse install` now pairs a browser that has the extension but isn't paired yet, including over SSH.
---
## Fixes
- `browse install` treated a browser with the extension added but not paired as having no extension, and told you to add it from the Chrome Web Store again. It now pairs it, or prints a one-time code to enter when it can't open the browser itself (for example over SSH).
- browse remembers an unpaired browser for 10 minutes instead of 65 seconds, and the onboarding page says what install will do.
