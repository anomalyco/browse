## Improvements
- The install scripts download browse from anoma.ly/release and check each file's size and SHA-256 before installing it. `--version` still installs older versions from npm.
- Installed binaries check for updates at launch and then hourly instead of once a day, and follow staged rollouts. npm installs still update through npm.
