## Fixes
- The relay no longer shuts itself down when no agent is connected, so it keeps checking for updates in the background.
- Updates are checked even with auto-update off (nothing is installed), for relays started from a terminal, and for installs browse doesn't recognize.
- The first check runs at launch instead of a minute later, and browse makes the request itself instead of running curl.
- Any version that differs from the one running is an update, so a rollback reaches everyone too.
- A relay started from a terminal installs updates but keeps running the old version until you restart it.
