## Major
- new onboarding: one page that checks each step live. ask your agent to set browse up, or run one line yourself. separate steps for an agent on another computer.
- one line install: `curl -fsSL https://opencode.ai/browse/install | bash` (windows: `irm https://opencode.ai/browse/install.ps1 | iex`). no node or npm needed, browse is a single binary now.

## Improvements
- `browse install` sets up the agents it finds, shows the mcp entry for any other agent, and sends you to the chrome web store if the extension isn't there yet. an agent running it sets up only itself. `--remote` for a browser on another computer.
- settings moved to their own page.
- removed the deadbolt integration and the `signin` tool. your own site secrets still work.
