## Improvements
- npm, bun, pnpm, yarn, volta, npx and bunx installs check the release service for the latest version, like install script installs already did, and then install it with their package manager.
- Right after a release, while npm hasn't caught up yet, global installs quietly try again later instead of reporting an error.
