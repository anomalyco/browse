## Major
### One-command setup
Run `npx @opencode/browse install` once. It pairs the extension with Browse on your computer, offers to add Browse to opencode, Claude Code, Cursor, Codex, VS Code and Windsurf, and only says it's ready once your browser is connected. The extension's page shows the one next step and turns green when it's done.

### Safer by default
The extension only obeys a Browse install it's paired with, agent code runs in a sandbox, cookies and site data stay limited to the pages an agent uses, and passwords you save are typed only on the sites you allow.

## Improvements
- Agents open tabs in the background of your window, grouped and collapsed, without taking focus. A separate window is an option.
- Settings on the extension's page for grouping, idle tab cleanup, the agent cursor, human-like input and handoff notifications.
- Several browsers can connect to one Browse install, and each agent session stays in the browser it started in.
- Recordings show only the page, with nothing from Browse in the frame.
- Bot challenge pages are recognised: the agent waits for automatic ones and hands interactive ones to you.
- Opt-in domain allowlists per session.
- When the extension and the command line don't match, both say which one to update.

## Fixes
- Agent tabs survive the extension restarting in the background, and no longer pile up.
- PDF pages, back and forward navigation, and screenshots of background tabs no longer get stuck.
- Large results and stuck scripts no longer freeze Browse.
- A forgotten network capture no longer blocks updates.
- Status for recordings with no session named now explains which session to pick instead of failing.
