## Improvements
- `tabs` with action `new` and an `id` like `work-mail` returns that tab, without navigating it, or opens it if it's gone. Every tool and the `--tab` flag accept the id, and `tabs` lists it with its last use and whether a call is running on it. A second call on a busy named tab gets a clear error instead of interleaving.
- `keepOpen: true` on a new tab keeps idle cleanup from closing it. Other agent tabs still close when idle, named or not.
- A new `groupCollapse` setting leaves agent tab groups expanded or collapsed the way you set them.
- When you close Chrome's debugging bar, a notification explains that browse lost its tabs.

## Fixes
- Updates were never applied while an agent was connected, because the relay waited for every agent to quit. It now restarts onto a new version as soon as no call is running, and agents reconnect by themselves. Global npm, bun, pnpm and yarn installs install updates the same way.
- Two browsers pairing at the same moment could drop one browser's pairing.
- Read-only tabs refuse input tools.
- `browse uninstall` no longer has files recreated by a relay that was still shutting down.
- On Windows, the relay runs in a job so it stops with its agent, and the binaries can be signed.
