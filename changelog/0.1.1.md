## Improvements
- Every agent tab and lent tab keeps its id when Chrome restores it after a browser restart.
- `tabs` with action `new` and an `id` like `work-mail` returns that tab if it exists, without navigating it, or opens it if it doesn't. Every tool that takes a tab accepts that id.
- Tabs with a chosen id never close when idle, and a second call while one is running on them gets a clear busy error instead of interleaving.
- `tabs` lists each tab's chosen id, last use and whether a call is running on it.
- Agents share one view of the browser's agent tabs: the per-agent tab isolation is gone. Agents still only act on the tabs they were given.
- The extension asks for the `sessions` permission, which it uses to keep tab ids across restarts.

## Fixes
- Snapshots of pages with a main landmark no longer miss content, and say what's left outside the main area.
- The extension reconnects after a relay restart without showing "reconnecting" when it isn't.
- The MCP server starts in the right folder on Windows.
