---
## Fixes
- An unhandled error in an agent's script no longer stops browse for every agent.
- Agent tabs no longer hang in Vivaldi, and a navigation that could crash Vivaldi and Chrome is gone.
- browse no longer gets stuck when a tab takes too long to attach; it gives up and closes that tab.
- Screenshots of background agent tabs are no longer blank.
- Closing Chrome's "started debugging this browser" bar releases every tab cleanly: agent tabs stay open until they're idle, lent tabs go back to you, and the agent is told what happened.
- When an agent's tabs close, their empty tab group goes away too.
- Pairing works on Windows npm installs.
- Files agents save (screenshots, downloads) are only readable by you.
- webmcp calls work on newer Chrome versions.
- `browse uninstall` removes the binary when browse's folders were customized, and custom XDG folders no longer break pairing.
- `browse install --help` (and other setup commands) shows help instead of running.

## Improvements
- The stable extension download is now named browse-extension-<version>.zip.
