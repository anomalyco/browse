## Major
### Updates that finish on their own
browse now waits until no agent is using the browser before replacing itself, and agents pick up the new version without a restart. Before, an update could leave agents failing with "relay is newer than CLI" until they restarted, or keep a machine on an old version for hours.
### Each agent gets its own session
Agents and subagents that share one OpenCode process each keep their own browse session, so one agent no longer loads pages in another's tab, and end-of-task cleanup only closes the agent's own tabs.
## Improvements
- Many agents running heavy scripts at once share the relay fairly, so one busy agent no longer slows every other agent down.
- A busy relay gets more time to answer before an agent treats it as gone.
- Pi is a supported agent in `browse install`.
- Adding browse keeps YAML agent configs intact.
- The install script checks pinned npm downloads against their published integrity and cleans up after a failed download.
## Fixes
- A browser disconnect during a screen recording no longer stops the relay for every agent.
- After an update, agents on installs from before 0.0.11 no longer hang on browse calls.
- A tab Chrome closed without telling the relay no longer blocks updates or new sessions.
- Stopping the relay works even when an agent's work is stuck.
- An extension that stops answering is reloaded after a minute.
- Long-running scripts on a loaded machine are no longer stopped for using too much CPU.
- Scrolling gives up quickly when an element can't move, instead of scrolling for seconds.
- `snapshot({ within })` works when the selector matches several elements or none.
- Network captures keep code samples from DocC documentation (code listings and inline code) in HAR files.
- Windows PowerShell 7 can run the install script.
