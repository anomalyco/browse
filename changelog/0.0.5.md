## Fixes
- Popups opened by several agents at the same time no longer time out.
- Snapshots of very large pages are about 25 times faster and no longer time out when several agents work at once.
- After an update that changes how Browse pairs, an unpacked extension says to reload it on the extensions page, and future updates reload it by themselves.
